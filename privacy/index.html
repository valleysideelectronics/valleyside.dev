Website privacy

This note covers the valleyside.dev website. The Lake Cumberland app has its own privacy policy.

Last updated September 28, 2026

No cookies, analytics or tracking

This website doesn’t set cookies, doesn’t use analytics, and doesn’t track you. Every file it uses, including its fonts and images, is served from valleyside.dev itself, so a visit doesn’t send your information to anyone else.

Hosting

The site is hosted on GitHub Pages. GitHub may log visitors’ IP addresses for security purposes. See GitHub’s privacy statement for details.

If you email us

If you email us, we keep your email so we can reply to you.
