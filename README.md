# valleyside.dev

The website of Valleyside Electronics LLC, served by GitHub Pages at https://valleyside.dev.

The Lake Cumberland privacy policy and terms are generated from the app repo (`lake-cumberland/docs`) with `python build.py`; edit them there, not here.

- Plain static HTML with one shared `style.css`. No JavaScript is needed for content, and the site makes no third-party requests (no analytics, cookies or CDNs).
- `fonts/InterVariable.woff2` is Inter 4.1 (https://github.com/rsms/inter), SIL Open Font License 1.1; see `fonts/Inter-LICENSE.txt`.
- `favicon.svg` and `logo.png` are the Valleyside logo mark; `og-image.png` (1200×630) is the social preview image.
- `drafts/` holds unpublished pages and is in `.gitignore`. Nothing public links to it.
